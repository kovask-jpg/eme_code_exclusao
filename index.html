Exclusão de Conta - Eme Code

O Eme Code permite que os usuários excluam suas contas diretamente pelo aplicativo, de maneira simples e automatizada.

1. Como excluir sua conta pelo aplicativo

Para solicitar a exclusão, o usuário precisa estar conectado à sua conta no Eme Code.

  1. Abra o aplicativo Eme Code.
  2. Entre na sua conta utilizando o login do Google.
  3. Acesse a seção de configurações do aplicativo.
  4. Com a conta conectada, o botão Excluir minha conta ficará disponível.
  5. Toque no botão e confirme que realmente deseja excluir sua conta.
  6. Após a confirmação e a autenticação necessária, o aplicativo realizará automaticamente a exclusão da conta.

2. Quais dados serão excluídos?

Atualmente, o Eme Code utiliza o Google Firebase Authentication para realizar a autenticação dos usuários.

Quando a exclusão é concluída, a conta correspondente é removida do Firebase Authentication, incluindo os dados de autenticação associados a ela.

Na versão atual, o aplicativo não mantém projetos, arquivos, histórico de compras ou outros dados pessoais associados à conta em um banco de dados na nuvem.

3. Dados armazenados no dispositivo

Os projetos, arquivos e demais conteúdos criados ou salvos localmente pelo usuário permanecem armazenados no dispositivo.

A exclusão da conta não apaga automaticamente esses arquivos locais. O usuário poderá removê-los diretamente pelo próprio aplicativo ou pelo armazenamento do dispositivo.

5. Sobre a conta Google

A exclusão remove somente a conta utilizada para autenticação no Eme Code. Ela não exclui a conta Google do usuário.

Importante: a exclusão da conta do Eme Code é uma ação permanente. Antes de confirmar, certifique-se de que deseja realmente excluir sua conta.
